# lo-meta

lo 生态**权威文档仓库**（总纲 + 规格）。

本仓库持有 lo 生态跨仓库的规范文档，供 7 个代码仓库引用：

| 路径 | 内容 |
|---|---|
| `ecosystem/AGENTS.md` | **生态总纲**（唯一权威）：契约铁律 §1、各仓库速查 §2、开发流程 §3、测试 §4、文档 §5、审查 §6、陷阱 §7、边界速查 §8、版本节奏 §9、协议概念 §10、快速开始 §11、**不可触犯边界 §12（7 类）** |
| `specs/` | 生态规格文档（002 能力协议 / 006 边界 / 010 协议收敛 / 012 插件运行时 / 013 插件系统审计 等） |

## 如何被使用

- **opencode**：全局 `~/.config/opencode/opencode.jsonc` → `instructions` 指向
  `ecosystem/AGENTS.md`，所有项目会话自动加载；各仓库 `opencode.json` 的
  `references` 亦指向本仓库（`ouuabb/lo-meta`）。
- **各仓库 AGENTS.md**：为薄入口，指向本仓库总纲。
- 本仓库目录名在本地工作区为 `docs/`（与 `lo` 仓库目录名 `log/` 同理，远程名与本地目录名可不同）。

## 变更纪律

- 总纲/规格改动需经审查，且同步检查各仓库薄入口与 references 是否仍一致。
- 环境无关：文档只用仓库名，不依赖本地目录布局。
